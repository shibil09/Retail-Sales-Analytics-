# Retail-Sales-Analytics-
Developed an end-to-end retail sales analytics solution using Excel, SQL, Python, and Power BI to clean data, analyze sales and customer behavior, perform customer segmentation, and create interactive dashboards for business insights.

* Cleaned, transformed, and analyzed retail sales data using Excel, SQL, and Python.
* Performed sales, product, customer, staff, and inventory analysis using SQL queries and Python.
* Applied RFM analysis and KMeans clustering for customer segmentation.
* Developed an interactive Power BI dashboard with KPIs, sales trends, top products, customer segments, and inventory insights.
* Built an end-to-end ETL workflow from Excel data cleaning to SQL processing and Power BI visualization.
